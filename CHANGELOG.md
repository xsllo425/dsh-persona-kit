# Changelog

## Unreleased

- **The rebirth feature is gone.** The context-full notice, the `handoff_new_session` tool (`lib/handoff.js`), the carry-role switch on a new session, the per-role/per-track `rebirths` count and its affinity weight, the "· N 转" / "Rebirth N" title suffix, the five rebirth achievements and their badges are all removed. The chat-heat bar stays — it is now a plain context visualisation against a fixed full scale (`HEAT_FULL_TOKENS`, 1M), no longer tied to any reminder threshold. The token measurement that feeds it (`contextTokensOf` / `creditContext`) is kept.
- The bond meter reads the same number the rebirth notice does. The panel measured the *role's* credited context with the absolute `triggerTokens`, while the notice measured the session with `triggerPercent` of the real window, so on a 1M-token model the meter sat at 100 % long before any reminder and the two disagreed about what "full" meant. Both now go through `triggerAt()` in `lib/bond.js`, which turns the percentage into tokens against the window the last reading was taken against (`store.windowOf`), falling back to the absolute value only when no window is known.
- Chat heat no longer climbs to 100 % on its own. The role credits were fed from `tokenMeter.measure().totalTokens`, a *lifetime* counter that re-counts the whole context every step — one real session carried 189,797,436 credited tokens against a 198,187-token context (957×), and 66 of 212 sessions were inflated. Credits now come from `contextTokensOf()`, which reads the context-pressure projection, rejects a meter reading larger than 1.5× the window, and is shared with the rebirth notice. Files written by the old build repair themselves on load (`repairCredits` in `lib/store.js`): credits are scaled back proportionally so they fit the session total, and the fix is written back without waiting for the next mutation.
- The fourth badge of a batch is no longer swallowed. The server sends up to four fresh badges, the toast drew three, and all four were marked as seen — so anything past the third was marked read without ever being on screen. The toast now reports only the three it drew, and the rest stay pending for the next poll.
- A badge whose definition has left the library is marked seen instead of being re-examined on every poll. Deleting a role (or a badge from a card) used to leave its key in `state.json` forever, permanently unread.
- `POST /level` no longer creates a session. It accepted any id and wrote `{levels:{...}}` into `state.json` for it, so a typo — or anything else that could reach the loopback port — left junk sessions that the panel then listed. The route answers `422 unknown session` when the host can answer for the session table, and stays permissive when it cannot.
- An oversized request body answers **413**, not 500. `readBody` / `readRaw` threw a plain `'too large'` error and the route's catch turned everything that was not a 422 into a 500, which reads as a plugin crash rather than "your body is too big".
- `/memes-api` answers `400 unknown pack` for a pack id that does not exist, matching `/memes-export`. It used to fall back to the active pack silently, which hid a client typo behind a plausible-looking list; omitting `packId` (or asking for `all`) still returns the default.
- The `ghost` block in `config.json` is dead config — no code has read it since the grey-suggestion removal — and is ignored if a config still carries one.
- The **grey suggestion text** is gone from the plugin entirely. It predicted what you might type next and drew it inside the composer, which took a second model call per turn, sent the last six messages along with it, and had little to do with the persona itself — use a plugin dedicated to input prediction if you want it back. Removed with it: the whole `lib/ghost.js` module and the `/suggest`, `/sent`, `/event` routes, the `ghost` config block, the composer's mode switch, the Tab / → accept and ↑ / ↓ sent-history keys, the `.dsh-pk-ghost` overlay and its CSS, the `ghostAccepts` counter, and the 「心有灵犀 / In tune」 badge — the catalog is now **34 badges in 7 series**. `tests/ghost.test.mjs` and `tests/ghost-cache.test.mjs` went with it.
- The grey ghost suggestion text now anchors accurately inside the input box instead of jumping to the bottom toolbar. The layer was styled with `position:fixed` and used global viewport coordinates (`r.left`/`r.top`), which got offset incorrectly when ancestor cards introduced containing blocks or during dynamic height layout. It now uses `position:absolute` anchored to the composer card / overlay slot with relative delta coordinates (`r.left - rAnchor.left`, `r.top - rAnchor.top`), ensuring the ghost text is always mapped directly onto the composer input.
- The composer panel now follows the host theme instead of painting itself white. Every surface used `var(--dsw-alias-bg-elevated, #fff)`, but DSH has no `bg-elevated` token at all, so the `#fff` fallback always won and the popover, overlay cards and the toast stayed white — while the text colour *did* switch to `--dsw-alias-label-primary`, which in the dark theme is near-white. Surfaces now use the real tokens (`bg-layer-1` / `bg-layer-2`), borders use `--dsw-alias-border-l2`, shadows use `--dsw-shadow-lv3`, the error line uses `--dsw-alias-state-error-primary` and the overlay scrim uses `--dsw-alias-bg-mask-1`. Every token was checked against the bundle: both theme blocks define each of them (`#0000001a`/`#ffffff1f` for the border, `#0000003d`/`#00000080` for the scrim), and the panel CSS was rendered with the dark-theme values to confirm the text is readable.
- The achievements panel's role picker no longer opens a white sheet in the dark theme. It is a native `<select>`, and a native option list is painted by the UA from its own palette — the rule only set `background:transparent` on the closed control, so the dropdown itself fell back to the platform white with near-white option text. The closed control now carries `background-color` / `color` itself, `option` repeats the same pair, and `option:checked` mixes the accent into the layer. Two details were needed to make it stick: the accent mix has to keep a fallback (`var(--pk-accent, #d9a514)`) because the achievements overlay never sets `--pk-accent`, and without one `color-mix()` is invalid at computed-value time and the checked row falls back to the UA white — which is exactly the white strip that reappeared in the reported screenshot. Verified by reading back `getComputedStyle` from the actual rules extracted out of `lib/client.js`: the plain rows compute to `rgb(35, 35, 36)` and the checked row to the accent mix, instead of `rgba(0, 0, 0, 0)`.
- Session routes now find a session under either key shape. The host's own id is `session-<uuid>` while the role tables and the `/sessions` map key on the bare uuid, so `/probe`, `/sent` and `/timeline` used to answer `{ok:false}` for the latter. `/timeline` also read an undeclared `got` and threw on **every** call — the route answered 500 and no timeline ever came back. `tests/routes-session.test.mjs` pins both.
- The grey suggestion no longer fails "now and then". Three causes stacked up: the server cached an **empty** answer under the same key as a real one, so the client's own retry was answered from the cache in a millisecond and could never produce a line; the *normal* prompt told the model to output nothing when the next step was unclear, which is most of the time; and the client asked only on the single frame where "running" flipped to false, so a remount or a box that had been typed into never asked again. Now only a real line is cached, the prompt always asks for something to press Tab on, and an empty, idle box asks again once per finished turn (throttled to 9 s, so an empty answer cannot become a poll). `tests/ghost-cache.test.mjs` pins the cache rule.
- Saving state no longer loses an update when Windows briefly holds the file open. Replacing `state.json` and the role-session file used a bare `writeFileSync` + `renameSync`, which fails with `EPERM` when another handle has the target open; the debounced flush then swallowed the error and left the change queued until the next user action. Both now go through `lib/atomic-write.js`, which retries the transient Windows codes and falls back to an in-place write instead of dropping the data. A failed flush also reschedules itself on a backoff (1s doubling to 30s) instead of waiting for the next `touch()`.
- Rebirth reminders no longer stop at two. The notice used to fire once at `triggerTokens` (default **400k**), a firmer one at `secondTriggerTokens` (default **500k**), then never again — so a session that carried on for another 500k tokens got no help at all. `asked.json` still records a count per session (`{sid: n}`, old plain-id files read as one), but the count is now a *band*, not a budget: the first notice at the trigger, then one more every time the context crosses another `secondTriggerTokens − triggerTokens` wide step (500k → second notice, 600k → third, 900k → sixth…). The wording was rewritten to match — nothing claims to be "the last reminder" any more, and each notice is labelled with its own number (`（上下文提醒·第三次）` / `notice 3`), which needed Chinese numerals past ten, so `numeral()` now covers 0–99.
- The **攻略 (affinity)** suggestion mode is gone. It generated a "line that would bring you closer" in the input box, which meant a second model call per turn, its own prompt cache of literary per-track style, and a result that read like novel dialogue rather than something you would actually send. Grey suggestions now have exactly two states — off, and "predict what you are about to type" — and `ghost.defaultMode` only accepts `"off"` or `"normal"`.
- The composer panel's sections are collapsible: **人设**, **说话强度**, **关系** (which already had its own fold and now shares the implementation, keeping its remembered state) and **输入建议**. Each one stores open/closed under `dsh-persona-kit/fold-<id>`, defaults to open, and shows a ▾/▸ caret in its title; the strength and suggestion titles keep naming the current level / mode while collapsed, so nothing needs opening to check.
- The sticker board no longer hides part of the library. It used to draw at most **240** cells and print 「只画了前 240 张,还有 544 张——用搜索或筛选取一部分」, so on a machine with 784 stickers two thirds of them simply were not there unless you happened to think of filtering. The cap is now a *page*: the first 240 render, reaching the bottom of the grid adds another page, and the grey line became a button that says 「已显示 {a} / {b} 张 —— 点这里或往下滑看剩下的」 so paging works even when the grid cannot scroll. Changing the search or the filters returns to the first page. Paging rather than one huge render is deliberate — a full board is thousands of nodes and thousands of image requests. Separately, cells are no longer cropped: `.mp-cell` used `background-size:cover` inside a fixed square, and a sampled 120 stickers of the local library gave 40 portrait / 53 square / 27 landscape (ratios 0.56 – 1.78), so anything not square lost its top and bottom. Cells now use `contain`, matching the hover preview, which already did. `tests/client-render.test.mjs` pins the paging: 300 stickers → 240 cells, scroll to the bottom → all 300, and the hint disappears once nothing is left.
- A session whose token meter could not be reached used to skip silently — indistinguishable from "below the threshold". It now logs one warning naming the reason, so a dead meter cannot hide the reminder forever.
- The reminder measures what is actually in the context. It used to read whatever number came first, which for a long session was the *lifetime* total (every step re-sends the whole context — a 16 % session showed 189 million tokens and fired the final notice at once). It now reads the context-pressure projection, rejects anything larger than the window, and takes percentages when configured: `triggerPercent` / `secondPercent` (1-99) win over `triggerTokens` / `secondTriggerTokens` whenever the window is known.

- Achievements grew into a catalog: **34 badges in 7 series** (chat, days, meetings, bond, working together, role, secrets) — after the five rebirth badges and the 「心有灵犀 / In tune」 badge were removed above (27 global across 6 series + 7 role badges; a role card's own extras come on top). The panel is now a seal wall with a stats header (badges, days, current streak, best streak, turns), per-series counts, filters for earned / still waiting, and a details line under the filters. Three **secret** badges keep their condition — description, threshold and progress — on the server until they are earned; the panel only learns the name before that.
- Switching sessions no longer makes the composer pill fall back to the plain 「人设」 label: a new `GET /sessions` answer says which role every session is on, so the pill draws that role straight away while `/session` for the new session is still in flight.
- Chinese is now the default language (`"language": "zh"`; `"auto"` still follows the machine).
- Six ready-made roles in `presets/roles` (`node tools/install-examples.mjs --presets`), with each role's own sticker pack in `presets/meme-packs`.
- README rewritten as a landing page; the full reference moved to `docs/MANUAL.md`.
- Folds in `dsh-meme`: the sticker picker, multi-pack library, ZIP import/export, the ops panel and click-to-zoom. `send_meme`, the market, AI learning and IM delivery are intentionally left out.

## 0.1.0 — first release

A single plugin for DeepSeek Harness that brings together:

- **Roles**: library of `ROLE.md` folders, `/role`, a role remembered per session, a short notice written into the chat on a switch.
- **Intensity slider (1–5)** with the role's own picture on the knob; level texts live in the role card.
- **Stickers** bound to the role's own packs, picked by tone with a cadence set by the level; `send_sticker` for the model; stickers are identified by file, never by description.
- **Relationship tracks** — friend, partner, family (daughter / younger sister / elder sister / mother, purely familial) and lover (gentle, non-explicit, no assumptions about anyone's gender) — each with its own history, titles and way of growing.
- **Rebirth**: continue in a fresh session when the context fills up; affinity, titles and the role carry over.
- **Achievements**: plain-data definitions plus per-role ones in the role card, including phrases a role says.
- **Avatars**: a picture and name above or beside each reply, relationship or affinity under the name; optionally replaces the name and picture on the sidebar account button.
- **Grey suggestions** (off by default): *normal* predicts your next message, *affinity* writes a literary line that brings you closer in the voice that suits the relationship; Tab / → to take it, ↑ / ↓ for your sent history.
- **Tool gate** (optional): heavy tool groups start hidden and come back per session on request.
- **Chinese and English**: menus, titles, achievements and the text sent to the model (`language`: `auto` | `zh` | `en`).
- Example role and an original 12-face sticker pack; `tools/install-examples.mjs` copies them into your DSH home.

Folds in and replaces the author's earlier local plugins `dsh-handoff`, `dsh-tool-gate`, `dsh-meme-auto` and the persona button of `dsh-local-tweaks`.
